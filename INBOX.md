# wiz6 INBOX

Freeform jot pad. Add anything — bug, idea, half-baked thought, "remember to look at X". One item per bullet. Phrasing doesn't matter; Claude will clarify before processing.

**Workflow**:
- You add bullets and commit them yourself (e.g. `inbox: spaceship colors wrong`). Raw wording stays in history.
- Claude reads INBOX on session start (or when you say "check inbox"), asks clarifying questions, then commits one batch that translates each bullet into a TODO.md entry and removes it from here.
- Empty INBOX = nothing to process.
